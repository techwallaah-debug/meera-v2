## 🚀 Quick Start Guide

### Prerequisites
```bash
# Install dependencies
- Node.js 20 LTS
- Python 3.11+
- Docker & Docker Compose
- MySQL 8.0 (via Docker)
- Redis (via Docker)
- Elasticsearch (via Docker)
```

### Step 1: Start Infrastructure
```bash
docker-compose up -d
```

### Step 2: Setup Backend
```bash
cd backend
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Step 3: Start Services
```bash
# Start each service in separate terminal
cd services/user-service/src && python main.py
cd services/content-service/src && python main.py
cd services/product-service/src && python main.py
cd services/order-service/src && python main.py
cd services/search-service/src && python main.py
cd services/recommendation-service/src && python main.py
cd services/analytics-service/src && python main.py
cd services/notification-service/src && python main.py
```

### Step 4: Setup Frontend
```bash
cd frontend/mobile
npm install
npm start
# Run on iOS: npm run ios
# Run on Android: npm run android
```

### Step 5: Test APIs
- User Service: http://localhost:8001/docs
- Content Service: http://localhost:8002/docs
- Product Service: http://localhost:8003/docs
- Order Service: http://localhost:8004/docs
- Search Service: http://localhost:8005/docs
- Recommendation Service: http://localhost:8006/docs
- Analytics Service: http://localhost:8007/docs
- Notification Service: http://localhost:8008/docs
